# Как внести вклад

Спасибо за интерес к проекту! Формат свободный, но пара правил поможет.

## Идеи и баги

Открой **Issue** с заголовком, в котором понятна суть:

- для бага: ОС, версия Python, команда запуска, что ожидалось и что вышло;
- для идеи: зачем она нужна и кому.

## Pull Request'ы

1. Сделай форк, создай ветку: `git checkout -b feature/моя-фишка`
2. Ядро (`tgmsg/core.py`) не должно зависеть от rich/typer — это сознательное
   разделение, чтобы позже навесить GUI.
3. Новые флаги добавляются в `tgmsg/cli.py` (typer-опция) и при необходимости
   в `KNOWN_KEYS` в `tgmsg/config.py`, чтобы сохранялись в конфиг.
4. Проверь, что перед отправкой PR:

```bash
python -m tgmsg --version
python -m tgmsg --dry-run -n 3 -t "тест"   # должно пройти без ошибок
```

5. Оформи описание PR: что и зачем.

## Стиль кода

- Комментарии и сообщения — на русском, идентификаторы — на английском.
- Без лишних зависимостей: всё, что есть в stdlib, тянуть извне не нужно.

## Этика

Фичи, предназначенные для массового спама незнакомым людям, приниматься
не будут. Инструмент — для розыгрышей и автоматизации собственного ввода.
