Пусть консоль печатает за тебя

CLI-утилита: вставляет твой текст в активное поле ввода N раз и жмёт Enter. Мастер настройки, пресеты скорости, память настроек — и аварийная остановка одной клавишей.

Возможности

Всё, чего не хватало скрипту на 15 строк

01

Интерактивный мастер

Запусти tgmsg без аргументов — он сам спросит текст, скорость и количество. Enter принимает значение по умолчанию.

02

Память настроек

Ответы сохраняются в ~/.tgmsg.json. Настроил один раз — дальше каждый запуск это несколько Enter'ов.

03

Пресеты скорости

Четыре режима — от секунды до 0.08. Нужна своя пауза — флаг --delay точнее любого пресета.

04

Стоп одной клавишей

Esc останавливает мгновенно — до старта, во время отсчёта и даже во время паузы между сообщениями.

05

Репетиция

--dry-run проигрывает запуск по-настоящему, но не отправляет ничего. Работает даже без зависимостей.

06

Буфер не страдает

Содержимое буфера обмена сохраняется перед стартом и возвращается на место — даже если прервать Ctrl+C.

Установка

Три способа — выбери свой

Нужен Python 3.9+ (при установке поставь галочку «Add python.exe to PATH»).

Без установки просто

:: внутри папки проекта
pip install -r requirements.txt
python main.py

Скачай папку проекта и запускай из неё — установка не нужна.

Команда tgmsg рекомендую

cd C:\путь\к\tg-msg
pip install .
tgmsg

После установки утилита доступна из любой папки. Обновление: pip install --upgrade .

Через pipx чисто

pip install pipx
pipx ensurepath
pipx install C:\путь\к\tg-msg

Изолированное окружение, не трогает другие пакеты Python.

Готовый exe для друзей

pip install pyinstaller
pyinstaller --onefile --name tgmsg
  --hidden-import keyboard
  --hidden-import pyperclip main.py

Один файл dist\tgmsg.exe — Python не нужен.

Использование

Мастер или одной командой

Не указал флаг — спросит мастер. Указал — вопрос пропустит.

Мастер (Enter-Enter и полетели)

tgmsg

Текст сообщения (пися попа кака): го в катку
Скорость [1]медленно [2]обычно [3]быстро [4]максимум (2): 3
Сколько сообщений (10): 5
…и ещё пара Enter — поехали

Одной командой

tgmsg -t "привет" -n 10

репетиция без отправки:
tgmsg --dry-run -t "привет" -n 10

отправка по Ctrl+Enter:
tgmsg -t "привет" --send-key ctrl+enter

Своя пауза: --delay 0.7 — точнее любого пресета. Если сообщения «слипаются», чуть увеличь --paste-delay.

FAQ

Частые вопросы

«tgmsg» не является внутренней или внешней командой

Скорее всего консоль открыта со времён установки — закрой и открой новую. Не помогло: проверь pip show tgmsg, а запускай через python -m tgmsg. Полный разбор — в руководстве пользователя.

Куда улетают сообщения и от чьего имени?

В то окно, которое в фокусе, от имени твоего аккаунта — утилита просто имитирует клавиатуру: буфер обмена → Ctrl+V → Enter. Никаких подключений к Telegram у неё нет.

Сообщения вставляются, но не отправляются

У тебя в Telegram включена отправка по Ctrl+Enter. Запусти с --send-key ctrl+enter — или спросит мастер.

Как остановить посреди отправки?

Esc — мгновенно останавливает в любой момент (даже во время пауз). Ctrl+C в консоли — тоже вариант, буфер обмена восстановится в обоих случаях.

Работает на Linux / macOS?

Да, с оговорками: на Linux модулю keyboard нужны root и X11 (под Wayland — нет), на macOS дай терминалу разрешения Accessibility и Input Monitoring. Вставка на macOS автоматически Cmd+V.

Это законно?

Утилита — автоматизация твоей собственной клавиатуры: розыгрыши, рутина, напоминания. Массовые одинаковые сообщения незнакомцам Telegram расценивает как спам — жалобы ведут к ограничениям аккаунта.

Об ответственности

Утилита ничего не собирает, не имеет сетевого доступа и пишет только от твоего имени: текст проходит через твой буфер обмена и твою клавиатуру. Розыгрыш друга — нормальное применение; рассылка незнакомцам — нет: одинаковые сообщения подряд Telegram расценивает как спам, а жалобы получателей ведут к ограничениям аккаунта.
