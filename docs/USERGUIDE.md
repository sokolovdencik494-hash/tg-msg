## Что это такое

TG-MSG — утилита для командной строки, которая **сама печатает за тебя**:
копирует заданный текст в буфер обмена, вставляет его в то поле ввода,
где стоит курсор (Telegram, любой мессенджер, вообще любая программа)
и нажимает Enter — столько раз, сколько скажешь.

Типичное применение: розыгрыш друга в Telegram.

**Чего она НЕ делает:** не взламывает, не читает чужие сообщения, не работает
без твоего компьютера и всегда пишет от твоего имени.

## Как это работает

Никакой магии и подключений к Telegram — чистая имитация клавиатуры:

```
твой текст → буфер обмена → Ctrl+V → пауза → Enter → пауза → и так N раз
```

Поэтому:

- окно, куда идёт вставка, должно быть **открыто и в фокусе** — курсор
  должен стоять в поле ввода;
- всё это время ПК должен быть включён, а мышь и клавиатура — не заняты тобой;
- сообщение отправится **от твоего аккаунта**, как будто ты набрал его руками.

## Установка

### Что нужно

- **Windows** 10/11 (основная платформа; Linux и macOS — с оговорками, см. [Решение проблем](#решение-проблем))
- **Python 3.9 или новее**: скачать с <https://www.python.org/downloads/>
  → при установке **обязательно** поставь галочку **«Add python.exe to PATH»**

Проверка, что Python есть (в cmd или PowerShell):

```cmd
python --version
```

Если пишет «python не является внутренней или внешней программой» — попробуй `py --version`,
а если и это не помогло — переустанови Python с галочкой PATH.

### Вариант А: просто запустить из папки (без установки)

```cmd
cd C:\путь\к\tg-msg
pip install -r requirements.txt
python main.py
```

Запускать можно всегда так — установка никуда не денется.

### Вариант Б: установить как команду `tgmsg` (рекомендую)

```cmd
cd C:\путь\к\tg-msg
pip install .
```

После этого утилита доступна из **любой** папки:

```cmd
tgmsg
```

> Если пишет «"tgmsg" не является внутренней или внешней командой», хотя
> установка прошла успешно — **закрой и открой консоль заново**. PATH
> обновляется только у новых окон. Не помогло — см. [Решение проблем](#решение-проблем).

### Вариант В: через pipx (чистая установка «как у взрослых»)

[pipx](https://pipx.pypa.io/stable/) ставит утилиту в изолированное окружение,
не трогая остальные пакеты Python:

```cmd
pip install pipx
pipx ensurepath        # один раз; после — перезапусти консоль
pipx install C:\путь\к\tg-msg
```

## Первый запуск

Просто набери:

```cmd
tgmsg
```

Откроется мастер — вводи или жми Enter, чтобы принять значение в скобках:

```
╭────────────────── Мастер запуска ───────────────────╮
│  Заполни параметры — Enter принимает значение       │
│  в [скобках]                                        │
╰─────────────────────────────────────────────────────╯
  Текст сообщения (пися попа кака): го в катку
  Скорость:  [1] медленно  [2] обычно  [3] быстро  [4] максимум (2): 3
  Сколько сообщений (10): 5
  Отправлять по Ctrl+Enter? [y/N] (n):
  Секунд на переключение в окно (5):
Стартуем? [Y/n] (y):
```

Дальше:

1. Появится цветной отсчёт `5 4 3 2 1` — **за это время переключись в Telegram
   и кликни в поле ввода** нужного чата.
2. Утилита отправит сообщения, показывая прогресс-бар.
3. Готово: `Готово! Отправлено 5 из 5 · 3.2 с`

Твои ответы запомнятся: **в следующий раз — просто Enter-Enter-Enter**.

## Все способы запуска

### 1. Мастер (без аргументов)

```cmd
tgmsg
```

Спросит только то, что ты не указал. Идеально для запуска «на автомате».

### 2. Одной командой (без вопросов)

```cmd
tgmsg -t "привет" -n 10
```

`-t` — текст, `-n` — количество. Остальное возьмётся из прошлых настроек.

### 3. Полностью вручную

```cmd
tgmsg -t "привет" -n 10 --speed fast --send-key ctrl+enter --prepare 8
```

Комбинировать можно как угодно: указал флаг — вопрос не задаётся.

### 4. Репетиция

```cmd
tgmsg --dry-run -t "привет" -n 10
```

См. [Репетиция без отправки](#репетиция-без-отправки).

## Справочник параметров

| Флаг | Коротко | По умолчанию | Что делает |
|---|---|---|---|
| `--text` | `-t` | *спросит мастер* | Текст сообщений. Кавычки обязательны, если есть пробелы |
| `--count` | `-n` | `10` | Сколько сообщений отправить |
| `--speed` | — | `normal` | Пресет скорости: `slow` `normal` `fast` `max` |
| `--delay` | — | из пресета | Точная пауза после отправки, секунды (перекрывает `--speed`) |
| `--paste-delay` | — | `0.15` | Пауза между вставкой и Enter, секунды |
| `--prepare` | — | `5.0` | Сколько секунд даётся на переключение в окно |
| `--stop-key` | — | `esc` | Клавиша аварийной остановки |
| `--send-key` | — | `enter` | Чем отправлять: `enter` или `ctrl+enter` |
| `--paste-hotkey` | — | авто | Своя комбинация вставки (авто: `ctrl+v`, на macOS `cmd+v`) |
| `--dry-run` | — | выкл | Репетиция без реальной отправки |
| `--no-save` | — | выкл | Не запоминать эти настройки в конфиг |
| `--version` | — | — | Показать версию |
| `--help` | — | — | Справка по всем флагам |

Примеры:

```cmd
tgmsg -t "заспускаюсь через час" -n 1
tgmsg -t "напоминание" -n 100 --delay 60 --no-save
tgmsg -t "проверка" --paste-delay 0.3 --prepare 10
```

## Скорость отправки

Пресет — это пауза **между** сообщениями:

| Выбор в мастере | Пресет | Пауза | Скорость |
|---|---|---|---|
| 1 | `slow` | 1 с | ~1 сообщ/с |
| 2 | `normal` | 0.4 с | ~2.3 сообщ/с |
| 3 | `fast` | 0.2 с | ~4.5 сообщ/с |
| 4 | `max` | 0.08 с | ~10 сообщ/с |

- Твоя пауза: `--delay 0.7`
- Пауза между вставкой и Enter отдельно: `--paste-delay`

**Совет:** на быстрых скоростях Telegram может не успевать отрисовывать
сообщения — это нормально, они всё равно отправятся. Если сообщения
начинают слипаться (Enter срабатывает раньше вставки) — увеличь `--paste-delay`.

## Файл настроек

После каждого запуска настройки сохраняются в:

```
C:\Users\<ты>\.tgmsg.json
```

```json
{
  "text": "го в катку",
  "count": 5,
  "speed": "fast",
  "paste_delay": 0.15,
  "prepare": 5,
  "stop_key": "esc",
  "send_key": "enter"
}
```

- Его можно **править блокнотом** — при следующем запуске значения подхватятся.
- Разовый запуск без перезаписи конфига: `--no-save`
- Не хочешь, чтобы текст лежал в файле: запускай всегда с `-t "..."` — тогда
  в конфиг уйдёт он же… поэтому для секретных текстов используй `--no-save`.

Приоритет источников: **флаг командной строки → конфиг → встроенный дефолт**.

## Как остановить

Три способа, от самого быстрого к самому грубому:

| Способ | Когда работает |
|---|---|
| **`Esc`** (или твоя `--stop-key`) | В любой момент: до старта, во время отсчёта, во время пауз. Остановка мгновенная |
| **Ctrl+C** в окне консоли | Всегда; буфер обмена всё равно восстановится |
| Дождаться конца | Если уже поздно |

Статистика остановки покажет, сколько успело уйти: `Остановлено после 7 из 20`.

> Если целевая программа запущена **от администратора**, а твоя консоль — нет,
> клавиши могут не перехватываться. Запусти консоль от имени администратора.

## Репетиция без отправки

`--dry-run` проигрывает всё как в бою — отсчёт, тайминги, прогресс — но **не
трогает** ни клавиатуру, ни буфер обмена. Идеально, чтобы:

- проверить установку (`tgmsg --dry-run -n 3 -t "тест"`);
- прикинуть время отправки (`100 сообщений × 0.4 с ≈ 40 с`);
- побаловаться с флагами без последствий.

Кстати, `--dry-run` работает даже без установленных `keyboard`/`pyperclip` —
можешь проверить утилиту до установки зависимостей.

## Сборка exe-файла

Чтобы дать утилиту другу без Python:

```cmd
cd C:\путь\к\tg-msg
pip install pyinstaller
pyinstaller --onefile --name tgmsg --hidden-import keyboard --hidden-import pyperclip main.py
```

Готовый файл: `dist\tgmsg.exe`. Флаги `--hidden-import` обязательны.

Нюансы exe:

- Первый запуск медленный (распаковка) — это нормально.
- Некоторые антивирусы и SmartScreen не любят PyInstaller-файлы: жми
  «Подробнее → Выполнить в любом случае» или добавь в исключения.

## Обновление и удаление

**Обновление** (если ставил как команду):

```cmd
cd C:\путь\к\новой_версии\tg-msg
pip install --upgrade .
tgmsg --version
```

Распаковка новой версии поверх старой папки — нормально. Настройки в
`~/.tgmsg.json` переживут любое обновление.

**Обновление** (если запускал из папки): просто замени папку новой.

**Удаление:**

```cmd
pip uninstall tgmsg        :: для варианта Б/В
```

и удали папку проекта + `C:\Users\<ты>\.tgmsg.json`, если хочешь начисто.

## Решение проблем

### «"tgmsg" не является внутренней или внешней командой…»

Самая частая проблема. Причины по порядку:

1. **Ты не запускал `pip install .`** — команда появляется только после установки.
   Проверь: `pip show tgmsg`.
2. **Консоль открыта со времён установки** — закрой окно cmd и открой новое.
3. **Скрипты Python не в PATH.** Проверь:
   ```cmd
   where tgmsg
   ```
   Если молчит, а `pip show tgmsg` установку показывает, найди папку
   `...\Python310\Scripts\` (у тебя Python 3.10 — путь вида
   `C:\Users\<имя>\AppData\Local\Programs\Python\Python310\Scripts`)
   и добавь её в PATH: Пуск → «Изменение системных переменных среды» →
   PATH → создать → вставить путь. Перезапусти консоль.
4. **Обходной путь, который работает всегда:**
   ```cmd
   python -m tgmsg
   ```

### «pip не является командой» — используй

```cmd
python -m pip install ...
```

### Сообщения вставляются, но не отправляются

У тебя в Telegram включена отправка по **Ctrl+Enter** (Настройки →
«Отправка сообщений»). Запусти с:

```cmd
tgmsg --send-key ctrl+enter
```

### Текст вставился не туда

Утилита шлёт в **активное окно**. Во время отсчёта кликни именно в поле
ввода нужного чата. Нечаянно отправить «не туда» — главная угроза таких
утилит, поэтому в мастере есть финальное подтверждение «Стартуем?».

### Esc не останавливает

- Окно получателя запущено от администратора? Запусти свою консоль тоже от админа.
- Попробуй Ctrl+C в окне консоли.
- Замени клавишу: `--stop-key f12`.

### В консоли кракозябры вместо текста

```cmd
chcp 65001
```

Или используй Windows Terminal (в Win 11 он и так по умолчанию).

### Windows: «Отказано в доступе» / клавиши не работают в некоторых окнах

Программы с правами администратора «выше» обычной консоли. Запусти cmd
от имени администратора.

### Linux

- Команда `keyboard` требует **прав root**: запускай `sudo python main.py`.
- Нужен **X11**-сеанс: под Wayland глобальные перехваты клавиш не работают.
- Для буфера обмена поставь `xclip`: `sudo apt install xclip`.

### macOS

Дай терминалу разрешения: Системные настройки → Конфиденциальность и
безопасность → **Accessibility** и **Input Monitoring** → добавь своё
приложение терминала.

### WSL

Не работает и не заработает: у WSL нет доступа к реальной клавиатуре Windows.
Запускай из обычной Windows.

### Антивирус ругается на exe

Ложное срабатывание PyInstaller — известная вещь. Либо добавь в исключения,
либо собери сам из исходников (см. [Сборка exe](#сборка-exe-файла)) — так
доверие выше, чем к скачанным чужим exe.

## Правила и риски

Этот раздел — не формальность:

- **Не шали на незнакомых.** Жалобы на спам в Telegram ведут к ограничениям
  твоего аккаунта — вплоть до блокировки. Розыгрыш друга, который потом
  посмеётся — ок. Рассылка незнакомцам — нет.
- **10–20 одинаковых сообщений подряд** Telegram может счесть спам-поведением
  уже сам по себе. Самый быстрый пресет прибереги для ситуаций, где риск приемлем.
- **Ты отправляешь от своего имени.** Всё, что улетит — твоя репутация.
- Утилита не собирает и не отправляет никаких данных куда-либо: текст ходит
  только через твой буфер обмена.
