## Возможности

- **Интерактивный мастер** — запусти `tgmsg` без флагов, отвечай Enter'ом
- **Память настроек** (`~/.tgmsg.json`) — настроил один раз, дальше просто запускаешь
- **Пресеты скорости**: медленно / обычно / быстро / максимум
- **Аварийная остановка** стоп-клавишей (по умолчанию `Esc`) — даже во время паузы
- **Репетиция** `--dry-run` без реальной отправки
- Буфер обмена сохраняется до старта и **восстанавливается** после (даже при Ctrl+C)
- На macOS вставка автоматически `Cmd+V`, на остальных `Ctrl+V`
- Цветной баннер, панели, прогресс-бар с ETA, «горячий» отсчёт (typer + rich)

## Установка

```bash
cd tg-msg
pip install -r requirements.txt

# вариант А: запуск без установки
python main.py

# вариант Б: установить команду tgmsg (рекомендуется через pipx)
pip install .        # или: pipx install .
tgmsg
```

## Быстрый старт

### Способ 1: мастер (ничего не надо помнить)

```bash
tgmsg
```

```
╭─ Мастер запуска ──────────────────────╮
│  Заполни параметры — Enter принимает     │
│  значение в [скобках]                    │
╰──────────────────────────────────────────╯
  Текст сообщения (пися попа кака): го в катку
   Скорость:  [1] медленно [2] обычно [3] быстро [4] максимум (2):
  Сколько сообщений (10): 5
  Отправлять по Ctrl+Enter? [y/N] (n):
  Секунд на переключение в окно (5):
Стартуем? [Y/n] (y):
```

Ответы запоминаются: **в следующий раз — просто шесть Enter'ов**.

### Способ 2: одной командой

```bash
tgmsg -t "пися попа кака" -n 10                    # скорость из пресетов/конфига
tgmsg -t "го в катку" -n 5 --speed fast            # пресет скорости
tgmsg -t "тест" -n 3 --delay 1 --dry-run           # точная пауза + репетиция
tgmsg -t "привет" --send-key ctrl+enter            # если отправка по Ctrl+Enter
```

Приоритет значений: **флаг → конфиг → встроенный дефолт**.

## Скорость

| Пресет | Пауза | Кому подходит |
|---|---|---|
| `slow` | 1 с | большие тексты, чтобы успеть прочитать |
| `normal` | 0.4 с | дефолт |
| `fast` | 0.2 с | быстрый чат |
| `max` | 0.08 с | лавина (осторожно — см. «Этика») |

Точная пауза: `--delay 0.7` (перекрывает пресет).

## Флаги

| Флаг | По умолчанию | Описание |
|---|---|---|
| `-t, --text` | *спросит мастер* | Текст сообщений |
| `-n, --count` | `10` | Сколько раз отправить |
| `--speed` | `normal` | Пресет: `slow` `normal` `fast` `max` |
| `--delay` | из пресета | Точная пауза после отправки, с |
| `--paste-delay` | `0.15` | Пауза между вставкой и Enter, с |
| `--prepare` | `5.0` | Отсчёт до старта, с |
| `--stop-key` | `esc` | Клавиша аварийной остановки |
| `--send-key` | `enter` | `enter` или `ctrl+enter` |
| `--paste-hotkey` | авто | Переопределить вставку (авто: `ctrl+v` / `cmd+v`) |
| `--dry-run` | выкл | Репетиция без отправки |
| `--no-save` | выкл | Не запоминать эти настройки |
| `--version` | — | Версия |

## Конфиг ~/.tgmsg.json

Создаётся автоматически после первого запуска (если не передан `--no-save`):

```json
{
  "text": "го в катку",
  "count": 5,
  "speed": "fast",
  "paste_delay": 0.15,
  "prepare": 5,
  "stop_key": "esc",
  "send_key": "enter"
}
```

Можно править руками. Учти: текст лежит там в открытом виде.

## Механика и аварийная остановка

1. Сохраняем буфер обмена, регистрируем стоп-клавишу — `Esc` работает **ещё до отсчёта**.
2. Цветной отсчёт `--prepare` секунд (зелёный → жёлтый → красный): успей кликнуть в поле ввода.
3. Цикл: скопировать → `Ctrl+V` → пауза → `Enter` → пауза. Стоп-клавиша проверяется
   и во время пауз — остановка мгновенная.
4. В `finally` буфер восстанавливается — даже при Ctrl+C.

## Сборка в exe (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --name tgmsg \
    --hidden-import keyboard --hidden-import pyperclip \
    main.py
# готово: dist/tgmsg.exe
```

`--hidden-import` обязательны: модули импортируются лениво, и PyInstaller сам
их не увидит.

## Известные ограничения

- **Windows** — основная платформа, работает из коробки.
- **Linux** — `keyboard` требует `sudo` и сеанс **X11**; под Wayland глобальные хуки
  не работают. Для буфера обмена нужен `xclip` или `xsel`.
- **macOS** — дай терминалу разрешения *Accessibility* и *Input Monitoring*.
- **WSL** — не заработает: нет доступа к реальной клавиатуре Windows.
- Enter отправляет сообщение в Telegram, только если не включена опция
  «отправлять по Ctrl+Enter» — для неё есть `--send-key ctrl+enter`.

## Этика

Инструмент для розыгрыша друзей и автоматизации собственного ввода. Массовая
рассылка незнакомым людям — это спам: жалобы получателей ведут к ограничениям
аккаунта в Telegram. Не будь тем парнем.

## Структура проекта

```
tg-msg/
├── tgmsg/
│   ├── __init__.py     # версия
│   ├── banner.py       # ASCII-логотип с градиентом
│   ├── config.py       # память настроек (~/.tgmsg.json)
│   ├── core.py         # ядро: Settings, Speed, Stopper, iter_sends
│   ├── cli.py          # оболочка: мастер, флаги, панели, прогресс
│   └── __main__.py     # запуск: python -m tgmsg
├── main.py             # точка входа для PyInstaller
├── pyproject.toml
├── requirements.txt
└── README.md
```

Ядро (`core.py`) не знает про rich: если захочешь GUI — навесь окно на
`Settings` + `iter_sends()`, ничего не переписывая.
